# Credits

## Sound

Every sound in Megadados (effects and the TV music loop) is synthesized at runtime with the Web
Audio API in `src/audio/`. There are no audio files, so there is nothing to license or attribute.

## Fonts

- [Lilita One](https://fonts.google.com/specimen/Lilita+One) by Juan Montoreano, SIL Open Font License 1.1.
- [Baloo 2](https://fonts.google.com/specimen/Baloo+2) by Ek Type, SIL Open Font License 1.1.

Both are served through `next/font/google`.

## Art

The Megafy mascot, the die avatars, the category icons and the wheel are original work drawn in
code (SVG and Three.js) for this project. The mascot follows Megafy's own character sheet.
